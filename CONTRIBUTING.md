# Katkı ve içerik politikası

## Marka / görseller

- Lockheed Martin ve USAF ile ilgili görseller için `public/assets/README.md` (taşınmış `assets/README.md`) içindeki notları ve kaynak lisanslarını okuyun.
- Ticari marka kullanımı proje sahibinin sorumluluğundadır; gerekirse hukuk onayı alın.

## Geliştirme

1. `npm install`
2. `npm run lint:html`
3. Yerel: `npm run dev`  
4. Pages ile uyumlu derleme: `GITHUB_ACTIONS=true npm run build` (bash: `GITHUB_ACTIONS=true npm run build`)
